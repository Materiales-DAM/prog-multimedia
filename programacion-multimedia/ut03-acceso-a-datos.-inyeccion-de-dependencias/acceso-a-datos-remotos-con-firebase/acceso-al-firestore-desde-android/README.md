# Acceso al Firestore desde Android

Firestore es una solución flexible y escalable para almacenar y sincronizar datos en tiempo real. Combina la simplicidad de una base de datos NoSQL con funcionalidades avanzadas como consultas en tiempo real, sincronización sin conexión y una integración perfecta con otros servicios de Firebase.

Unir Firestore con Jetpack Compose permite crear aplicaciones modernas con una arquitectura sólida y una experiencia de usuario rica.&#x20;
