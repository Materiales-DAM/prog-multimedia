# Ejercicios ViewModel con data classes

Crea ventanas de creación de las siguientes entidades:

1. CreateFlightScreen: cada vuelo (Flight) tendrá los siguientes campos:
   1. Número de vuelo: Int
   2. Origen
   3. Destino
   4. Compañia
2. CreateStudentScreen: cada estudiante (Student) tendrá los siguientes campos:
   1. NIF: String
   2. Nombre
   3. Apellidos
   4. Edad
