# Ejercicios de componentes

1. Crea un composable de ventana de login. Carga una imagen que haga de logo de la aplicación (puedes usar el logo de cualquier página o crear el tuyo propio):
   1. Nombre de ususario
   2. Password
   3. Botón de aceptar
   4. Botón de limpiar
   5. Botón de Registrarse
2. Crea un composable de ventana de registro. Haz que el formulario sea bonito usando iconos:
   1. Nombre  de usuario
   2. Password
   3. Repite password
   4. Nombre y apellidos: dos TextField en la misma fila, apellidos debe ocupar el doble de ancho que nombre
   5. Email
   6. Bio: TextField multilinea que se expande a todo el alto disponible&#x20;
   7. Botón de aceptar
   8. Botón de cancelar
