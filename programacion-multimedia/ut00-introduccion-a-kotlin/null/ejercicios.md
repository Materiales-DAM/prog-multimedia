# Ejercicios

1. Crea una función getOrZero que reciba como parámetro un número entero opcional. Si el parámetro es null devuelve 0 y si no devuelve el valor del parámetro.
2. Crea una función printName que reciba un parámetro opcional llamado nombre. Si el nombre es null imprime "Nombre desconocido", si no imprime el nombre
3. Crea una función getLength que reciba un parámetro opcional llamado nombre. Si el nombre es null devuelve null, si no es null devuelve la longitud del nombre.
4. Crea una función first que reciba como parámetro una lista de enteros. Si la lista está vacía devuelve null, si no está vacía devuelve el primer elemento de la lista.
5. Un método average( numbers: List\<Double> ) que calcula la media de los números en la lista. Si la lista está vacía devuelve null.
6. Un método max( numbers: List\<Double> ) que busca el máximo de los números en la lista. Si la lista está vacía devuelve null.
7. Un método min( numbers: List\<Double>) que busca el mínimo de los números en la lista. Si la lista está vacía devuelve null.
